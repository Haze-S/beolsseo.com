# beolsseo.com 재기획 — 회사 우선(Company-first) 개편

- 작성일: 2026-08-06
- 대상: beolsseo.com 정적 사이트(index / dungeon / campaign / terms / privacy / 404 + assets/style.css)
- 원칙: 정적 HTML+CSS 범위 유지(YAGNI). CMS·프레임워크·빌드 도구 도입 금지.

---

## 1. 진단

- 회사 사이트인데 **모든 회사 표면이 던전 컴퍼니의 마왕 캐릭터로 덮여 있다**: 랜딩 히어로(maou_desk), 전 페이지 문의 밴드(maou_cheer), 404(maou_desk), OG 이미지(마왕 야근 일러스트)까지 — 처음 방문한 사람에게 "게임 하나 만드는 팀"으로 읽힌다.
- 히어로 카피 "밤새 **던전을** 지켰더니"와 eyebrow "Game & Platform Studio"가 회사 정체성을 게임 세계관에 종속시킨다. 사업자 업태(응용 SW 개발·공급, 전자상거래 중개, 정보 매개, 광고 등)와 앞으로의 서비스 확장을 담지 못한다.
- 랜딩의 프로젝트 소개가 제품 2개 전용 **풀블리드 피처 밴드(지그재그)** 구조라, 제품이 3개·5개로 늘면 랜딩이 무한정 길어지고 매번 밴드를 새로 디자인해야 한다. GNB도 제품명을 하드코딩("던전 컴퍼니", "campaign-hub")해 제품이 늘 때마다 내비게이션이 바뀐다.
- 반면 자산도 분명하다: 새벽 라벤더→살구→오렌지의 **아침 햇살 팔레트**, "벌써 아침"이라는 이름의 서사, 웨이브·칩·카드 등 재사용 가능한 컴포넌트, 잘 갖춰진 약관·개인정보 페이지. 이건 유지하고 그 위에 회사 브랜드를 다시 세운다.

## 2. 브랜드 원칙

### 2.1 브랜드 축 — "벌써아침"을 회사 이야기로

- 이름의 의미를 **게임 드립이 아니라 만드는 사람의 보편 경험**으로 되돌린다: 몰입해서 만들다 창밖이 밝아오는 순간, "벌써 아침이네". → 키워드: **몰입, 시작, 부지런함, 아침의 낙관**.
- 브랜드의 시각 주인공은 캐릭터가 아니라 **아침 그 자체**: 해(☀ 로고 마크), 일출 그라데이션(dawn1→dawn2→dawn3), 지평선. 기존 팔레트를 그대로 회사 브랜드 자산으로 승격한다.
- 회사 보이스: "게임사"가 아니라 **"소프트웨어와 서비스를 만드는 팀"**. 게임은 라인업의 한 카테고리다.
- 태그라인(회사 공통): **"만들다 보니, 벌써 아침."** — 밤샘 서사를 유지하되 던전·마왕 등 특정 IP 어휘를 제거한 형태. 푸터·OG·소개문에 공통 사용.

### 2.2 마왕(던전 컴퍼니 IP) 노출 수위 원칙

원칙 한 줄: **마왕은 던전 컴퍼니 영역(dungeon.html과 그 부속물) 안에서만 등장하고, 회사 공통 표면에는 절대 나오지 않는다.**

| 표면 | 마왕 노출 | 규칙 |
|---|---|---|
| 랜딩 히어로(index) | ❌ 금지 | 타이포+일출 그래픽만. 캐릭터·게임 어휘 불가 |
| 랜딩 프로덕트 카드 | ⭕ 썸네일 한정 | 던전 컴퍼니 **카드 썸네일 내부**에만 허용. 카드 밖 장식 금지 |
| 문의 밴드(index·campaign 등 회사/타제품 페이지) | ❌ 금지 | 해 그래픽 또는 무마스코트 |
| dungeon.html 전체 | ✅ 자유 | 제품 영역. 마왕·세계관·회사 드립 마음껏 |
| dungeon.html 문의 밴드 | ✅ 허용 | 제품 페이지의 연장이므로 maou_cheer 유지 가능 |
| 404 | ❌ 금지 | 회사 공통 표면. 해/아침 모티프로 교체 |
| 대표 OG(og.jpg — index·campaign·정책 페이지) | ❌ 금지 | 회사 브랜드 이미지로 교체 |
| 제품별 OG(og-dungeon.jpg 신규) | ✅ 허용 | dungeon.html 전용 OG에는 마왕 사용 가능 |
| 파비콘·로고 | ❌ 금지(현행 유지) | ☀ 유지 |
| 약관·개인정보 | ❌ 금지(현행 유지) | 중립 문서 톤 유지 |

### 2.3 톤앤매너 2계층

| | 회사 영역 (index, 404, OG, 정책, 푸터) | 제품 영역 (dungeon.html, campaign.html, 향후 제품 페이지) |
|---|---|---|
| 보이스 | 담백한 합니다체. 신뢰·따뜻함. 유머는 "벌써 아침" 서사 수준까지만 | 제품별 개성 전면 허용 — 던전 컴퍼니는 회사 드립·마왕 세계관, campaign-hub는 실무형 B2B 톤 |
| 비주얼 | 일출 그라데이션 + 타이포 + 기하 도형(해·지평선·창문 빛). 캐릭터 없음 | 제품 고유 아트 자유(밤 보라 밴드, 손그림 캐릭터 등) |
| 어휘 | 게임 세계관 어휘(던전·마왕·용사·결재 등) 금지 | 제한 없음 |
| 공통 불변 요소 | 헤더·푸터·팔레트·Jua/Noto 폰트 — 어느 페이지든 "벌써아침 사이트"임은 유지 | 동일 |

## 3. IA (사이트맵)

```
beolsseo.com
├─ index.html          회사 랜딩 — 미션 히어로 / #products 프로덕트 그리드 / #about 팀 / #contact 문의
├─ dungeon.html        제품 상세 — 던전 컴퍼니 시리즈 (게임 IP 영역, 마왕 자유)
├─ campaign.html       제품 상세 — campaign-hub (B2B 플랫폼 톤)
├─ (향후) <제품>.html   제품 상세 페이지 — 카드 규격에서 링크만 추가하면 됨
│    └ 별도 앱은 서브도메인(dg.beolsseo.com 등)으로 외부 링크 카드 처리
├─ terms.html          이용약관 (현행 유지)
├─ privacy.html        개인정보처리방침 (현행 유지)
└─ 404.html            회사 톤으로 교체
```

- **페이지 신설 없음.** 제품 3개까지는 index의 `#products` 그리드가 목록 페이지 역할을 한다. 제품이 4개를 넘으면 그때 `products.html`을 분리한다(2단계 이후 판단, 지금은 만들지 않는다).
- **GNB를 제품명 나열 → 카테고리형으로 변경**: `프로덕트(#products) · 팀(#about) · 문의(#contact)`. 제품이 늘어도 GNB가 안 바뀐다. 제품 페이지에서는 `프로덕트`가 `index.html#products`로 향한다.
- 푸터 "프로젝트" 컬럼만 제품 링크를 나열(제품 추가 시 여기와 카드 그리드만 수정).

## 4. 페이지별 상세 기획

### 4.1 index.html — 회사 랜딩

섹션 순서: ① 히어로 → ② 프로덕트 그리드(#products) → ③ 일하는 방식(#about 상단) → ④ 회사 정보(#about 하단) → ⑤ 문의 밴드(#contact) → 푸터

**① 히어로**
- 목적: 3초 안에 "다양한 서비스를 만드는 소프트웨어 팀"으로 인식시키기.
- 카피(채택 추천 A안 — 5장 참조):
  - eyebrow: `Software & Services` (← Game & Platform Studio 교체)
  - H1: `만들다 보니,` / `벌써 아침.` (accent는 "벌써 아침."에)
  - 서브: `벌써아침은 게임부터 웹 플랫폼까지, 쓰고 싶은 것을 직접 만드는 부산의 소프트웨어 팀입니다.`
  - CTA: `만들고 있는 것들 →` (#products, 현행 유지)
- 비주얼 지시: `hero-art`의 마왕 이미지를 제거하고 **CSS 일출 그래픽**으로 교체 — 지평선(수평선 1px 라인) 위로 떠오르는 반원 해(그라데이션 원 + 부드러운 glow), 배경은 기존 hero 그라데이션 그대로. 이미지 파일 불필요, div+radial-gradient로 구현. 모바일에선 해를 텍스트 뒤 배경 요소로 축소. float 애니메이션은 해의 은은한 상승(translateY)으로 전용.

**② 프로덕트 그리드(#products)**
- 목적: 제품 N개를 동일 규격으로 나열 — 확장의 기본 구조.
- 섹션 헤드: eyebrow `Products` / H2 `만들고 있는 것들` / 서브 `게임, 플랫폼, 그리고 다음 서비스들.`
- 구성: 기존 `.card-grid` + `.card` 재사용(a.card 링크 카드). 풀블리드 피처 밴드 2개는 랜딩에서 **제거**(해당 내용은 각 제품 페이지가 담당).
- 카드 2장(규격은 6장):
  - 던전 컴퍼니 시리즈 — 썸네일 dc-title.webp / 칩 `게임` `개발 중` / `마왕성도 결국 회사다 — 방치형 경영 RPG와 스핀오프로 이어지는 게임 시리즈.` / `자세히 →` dungeon.html
  - campaign-hub — 썸네일은 기존 CSS 카드 스택 축소판 또는 단색 아이콘 타일 / 칩 `플랫폼` `개발 중` / `사전예약·쿠폰·이벤트를 캠페인 하나로 묶어 운영하는 마케팅 플랫폼.` / `자세히 →` campaign.html
- (선택) 세 번째 자리에 비어있는 "다음 서비스" 플레이스홀더 카드: `☀ 다음 서비스 — 준비 중입니다.` 링크 없음. 확장 의지를 시각화. 어색하면 생략 가능.

**③ 일하는 방식 (#about 상단)**
- 목적: "게임+마케팅툴"이라는 라인업의 조합을 회사 철학으로 설명 — 게임사가 아니라 필요한 걸 직접 만드는 팀임을 못 박기.
- 카피:
  - eyebrow `About` / H2 `벌써아침은`
  - lead: `밤을 새워 무언가를 만들다 창밖이 밝아올 때의 "벌써 아침이네"라는 말에서 시작했습니다.` (현행 유지 — 이 문장은 회사 서사라 그대로 좋다)
  - 본문: `우리는 쓰고 싶은 것을 직접 만듭니다. 게임을 만들고, 그 게임을 알리는 데 필요한 마케팅 플랫폼도 직접 만들었습니다. 다음 서비스도 같은 방식으로 태어납니다 — 우리가 먼저 쓰고, 다듬어서, 내놓습니다.`
- 비주얼: 텍스트 중심(현행 `.section.alt` 유지). 캐릭터 없음.

**④ 회사 정보 (#about 하단, 신규 소절)**
- 목적: 사업자 정보를 푸터에만 두지 않고, 신뢰 표면으로 한 번 노출(B2B 문의 대비).
- 구성: 정의형 3~4줄 — `상호 벌써아침 · 대표 송현정 / 소재지 부산 / 하는 일 응용 소프트웨어 개발·공급, 온라인 서비스 운영`. muted 톤 소형 텍스트, 별도 섹션 없이 ③ 하단에 붙임.

**⑤ 문의 밴드(#contact)**
- 목적: 협업·도입·제안 창구.
- 카피: H2 `같이 만들 이야기가 있나요?` / `협업·도입·제안 모두 환영합니다.` / 버튼 `contact@beolsseo.com` (현행 유지)
- 비주얼 지시: **maou_cheer 제거.** `.mascot` 자리에 CSS 해 마크(⭕ 그라데이션 원 + 광선 8개, 또는 로고 ☀의 대형 버전)로 교체. float 애니메이션 재사용.

**푸터**
- 브랜드 문구 교체: `만들다 보니, 벌써 아침.` / `게임부터 웹 플랫폼까지 만드는 소프트웨어 팀.`
- 컬럼명 "프로젝트" → "프로덕트". 나머지 현행 유지.

**메타**
- title: `벌써아침 — 소프트웨어와 서비스를 만드는 팀`
- description/og: `벌써아침은 게임, 웹 플랫폼 등 다양한 서비스를 만드는 부산의 소프트웨어 팀입니다.`

### 4.2 dungeon.html — 제품 상세(게임 IP 영역)

- **구조·카피·마왕 노출 현행 유지.** 여기가 마왕의 집이다. 밤 보라 히어로, 세계관 섹션, 두 작품 소개, maou_cheer 문의 밴드 모두 그대로.
- 변경 2건만:
  - GNB를 새 공통 GNB(`프로덕트 · 팀 · 문의`)로 교체, `프로덕트`에 active.
  - OG 이미지를 제품 전용 `og-dungeon.jpg`(마왕 아트 사용 가능 — 기존 og.jpg를 리네임해 재활용 가능, 카피만 "던전 컴퍼니 시리즈"로)로 변경.

### 4.3 campaign.html — 제품 상세(B2B 플랫폼)

- 구조 현행 유지(Overview / Features / Use Case).
- 변경:
  - GNB 공통화(위와 동일).
  - **문의 밴드의 maou_cheer 제거** → 회사 공통 해 그래픽. campaign-hub는 B2B 도입 문의가 오는 페이지라 마왕이 신뢰를 깎는다.
  - Use Case 마지막 단락은 유지(첫 고객이 우리 자신이라는 문장은 회사 철학과 일치).
  - OG는 대표 OG(신규 회사 og.jpg) 사용.

### 4.4 terms.html / privacy.html

- 본문 현행 유지. GNB 공통화만 적용. (약관 1조의 "게임 및 관련 서비스" 표현은 서비스가 늘어날 때 "소프트웨어 및 서비스"로 확장 — 2단계.)

### 4.5 404.html

- 목적: 회사 톤의 가벼운 유머로 전환.
- 카피: H1 `404 — 아직 해가 뜨지 않은 페이지예요` / 본문 `찾으시는 페이지가 없거나, 주소가 바뀌었을 수 있어요.` / 버튼 `홈으로 돌아가기`
- 비주얼: maou_desk 제거 → 지평선 아래 반쯤 걸린 해 CSS 그래픽(히어로 일출 그래픽 축소 재사용).

### 4.6 OG 이미지(assets/img/og.jpg 교체)

- 대표 OG: 일출 그라데이션 배경(기존 OG 배경 톤 유지) + 좌측 타이포 `만들다 보니,` / `벌써 아침.`(accent 오렌지) + 하단 `소프트웨어와 서비스를 만드는 팀 · beolsseo.com` + 우측에 마왕 대신 **떠오르는 해 반원 그래픽**. 1200×630.
- 제품 OG: 기존 마왕 OG를 `og-dungeon.jpg`로 리네임, 카피를 `던전 컴퍼니 시리즈 — 마왕성도 결국 회사다`로 수정(여력 없으면 기존 이미지 그대로 리네임만 해도 무방 — 어차피 제품 문맥).

## 6. 프로덕트 카드 규격

제품이 5개, 10개가 되어도 이 구조만 반복한다. HTML 주석으로 템플릿을 index에 남겨둔다.

| 필드 | 필수 | 형식 | 예시 |
|---|---|---|---|
| name | ✅ | 한글 제품명(부제 가능) | `던전 컴퍼니 시리즈`, `campaign-hub` |
| tagline | ✅ | 한 줄 설명, 45자 이내, 마침표 1개 | `사전예약·쿠폰·이벤트를 캠페인 하나로 묶는 마케팅 플랫폼.` |
| category | ✅ | 칩 1개 — `게임` `플랫폼` `도구` `콘텐츠` 중 택1 (신규 카테고리는 여기 정의 추가 후 사용) | `게임` |
| status | ✅ | 칩 1개 — `개발 중` `베타` `운영 중` `출시` `서비스 종료` | `개발 중` |
| link | ✅ | 상세 페이지(내부 .html) 또는 서브도메인(외부, `↗` 표기) | `dungeon.html`, `https://dg.beolsseo.com ↗` |
| thumb | 선택 | 16:10 이미지 또는 CSS 타일(그라데이션+이모지/아이콘). 제품 아트 허용 — 캐릭터는 썸네일 안에서만 | `dc-title.webp` |
| platform | 선택 | muted 소형 텍스트 | `Android · Web`, `Windows` |

카드 마크업 규칙: `a.card > (.thumb) > .chips(category+status) > h3(name) > p(tagline) > (p.muted(platform)) > span.more("자세히 →")`. 기존 `.card`/`.chips`/`.chip` 클래스 그대로 사용, 신규 CSS 없음(썸네일 타일용 유틸 1~2개만 추가 가능).

칩 색 규칙: category는 유형별 고정색(게임=주황 계열 기본 칩, 플랫폼=blue 칩, 이후 카테고리 추가 시 색 1개씩 배정), status는 무채/기본 칩. 카드 안에서 마왕 등 제품 캐릭터는 **썸네일 이미지 내부**에만 존재할 수 있다(2.2 원칙).

## 7. 단계별 적용안

### 1단계 — 최소 수정 (기존 구현 최대 재사용, 반나절 분량)

목표: "마왕 회사"에서 "소프트웨어 팀" 인상으로 전환. 파일 신설 없음(OG 제외).

1. index 히어로 교체 — H1/서브/eyebrow를 A안으로, `hero-art`의 maou_desk를 CSS 일출 그래픽(div+그라데이션)으로 교체
2. index 프로젝트 영역 개편 — 피처 밴드 2개 제거, `.card-grid` 기반 프로덕트 카드 2장으로 대체(6장 규격)
3. index 문의 밴드 마스코트 제거 — maou_cheer → CSS 해 마크
4. campaign 문의 밴드 마스코트 제거 — 동일 처리 (dungeon은 유지)
5. GNB 공통 교체(6개 파일) — `프로덕트(#products) · 팀 · 문의`, 제품명 링크 제거
6. 404 교체 — 마왕 이미지 제거, 카피 `아직 해가 뜨지 않은 페이지예요`로, 해 그래픽 재사용
7. OG 교체 — 회사 대표 og.jpg 신규 제작(타이포+일출), 기존 마왕 OG는 og-dungeon.jpg로 리네임 후 dungeon.html에만 연결
8. 메타·푸터 문구 통일 — title/description "소프트웨어와 서비스를 만드는 팀", 푸터 태그라인 `만들다 보니, 벌써 아침.`, 컬럼명 "프로덕트"
9. about 본문 1문단 수정 — "다음 서비스도 같은 방식으로" 문장 추가(4.1-③)

### 2단계 — 이상적 개편 (제품 추가·B2B 문의 증가 시)

1. index #about에 회사 정보 소절 추가(4.1-④) + "일하는 방식" 3칼럼(직접 쓴다/작게 낸다/아침까지 다듬는다 등 원칙 카드)으로 확장
2. 프로덕트 카드에 "다음 서비스" 플레이스홀더 도입 및 신제품 카드 추가 운영(서브도메인 제품은 외부 링크 카드)
3. campaign.html을 B2B 톤으로 보강 — 도입 절차/문의 폼 대체 안내(mailto 유지), 스크린샷 추가
4. 제품별 OG 체계 완성(제품 페이지마다 전용 OG), dungeon OG 카피 리디자인
5. 히어로 일출 그래픽 고도화 — SVG 지평선+해 상승 모션(reduced-motion 대응), 404와 공유
6. 약관 1조 적용 범위 문구를 "소프트웨어 및 서비스" 일반형으로 확장
7. 제품 4개 초과 시 products.html 분리 검토(그 전엔 만들지 않음)
